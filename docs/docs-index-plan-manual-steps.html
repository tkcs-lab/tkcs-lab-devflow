Docs Index Checklist

Three things only you can do for the docs-index plan. One before /implement starts, two after the last merge. Your ticks are remembered in this browser.

Before implementation

Shrink the profile's must-read list

about 3 min

The plan moves docs/design.md, docs/profile-reference.md and docs/delivery.md. The profile lists them under docs.must_read, and the toolkit stops when a listed file is missing. The agent cannot edit the profile (the protect-paths hook guards it), so you do it on main first.

Done when the file on main lists only README.md under docs.must_read.

After implementation

Switch the profile to the docs index

about 5 min

Same protected file, now that the feature branch has created docs/README.md. Do this once the pull request is merged.

Report back one line: /dod: PASS or the failing row.

Schedule /docs tidy and update the board

about 10 min

A scheduled task needs the repository attached, which only the claude.ai interface can do. The status board rejects command: docs records until it runs the new code.

Report back what the first run ended with: docs clean, a tidy pull request, or an issue titled Docs tidy:.
